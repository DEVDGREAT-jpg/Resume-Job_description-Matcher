# 🤖 Resume–Job Matcher AI

An NLP-powered application designed to analyze resumes and job descriptions, extract relevant information, and calculate their similarity to help users identify how well a candidate's profile aligns with a job opportunity.

## 📌 Overview

Finding relevant job opportunities and understanding how well a resume matches a job description can be challenging.

Resume–Job Matcher AI uses Natural Language Processing (NLP) and text similarity techniques to compare resumes against job requirements and provide insights into their relevance.

## ✨ Features

* 📄 Resume text extraction from PDF files
* 🧹 Text preprocessing and cleaning
* 🛠️ Skill extraction from resumes and job descriptions
* 📊 TF-IDF-based text representation
* 🎯 Cosine similarity-based matching
* 🖥️ Interactive application built with Streamlit

## 🧰 Tech Stack

* Python
* Streamlit
* Natural Language Processing (NLP)
* TF-IDF
* Cosine Similarity
* PyMuPDF
* Pandas
* Scikit-learn

## ⚙️ How It Works

1. Upload a resume in PDF format.
2. Enter or provide a job description.
3. Extract and preprocess the text.
4. Identify relevant skills and information.
5. Convert the text into numerical representations using TF-IDF.
6. Calculate cosine similarity between the resume and job description.
7. Display the matching results.

## 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/resume-job-matcher.git
```

Navigate to the project directory:

```bash
cd resume-job-matcher
```

Create a virtual environment:

```bash
python -m venv venv
```

Activate it on Windows:

```bash
venv\Scripts\activate
```

Install the dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```
